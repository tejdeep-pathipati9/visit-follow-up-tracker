# Third-party UI sources

This UI incorporates and adapts publicly distributed components from:

- **Efferd Dashboard 5**: https://efferd.com/view/dashboard-5
  Official free registry: https://efferd.com/r/dashboard-5.json
- **Efferd App Shell 5**: https://efferd.com/r/app-shell-5.json
  App shell, navigation structure, theme switcher, responsive trigger, dashboard
  grid, and share-bar components were obtained through the official shadcn
  registry and adapted to the clinic domain. Retrieved October 30, 2026.
  Efferd is credited as the original design/component author. This project
  is not affiliated with or endorsed by Efferd. Refer to Efferd's published
  terms for use of its components: https://efferd.com/terms
- **shadcn/ui**: https://ui.shadcn.com — MIT-licensed components, installed
  through the official CLI. Source: https://github.com/shadcn-ui/ui
- **Radix UI**, **Lucide**, **Recharts**, **Geist**, and other dependencies retain
  their respective licenses in their npm distributions and source repositories.

Efferd's analytics example labels and static metrics have been replaced with
clinic records and existing API aggregates. Efferd branding, user identity, and
marketing links are not used as clinic identity or functionality.
